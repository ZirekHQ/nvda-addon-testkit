`wait_for` polls until a speech sequence matching the pattern arrives, since the given index —
it will not pass on a stale sequence spoken before `since`, and raises on timeout instead of
returning `None`.

Without `since`, `wait_for` snapshots `index()` at call time and only sees speech produced
afterwards; capture `index()` before a synchronous action and pass it as `since`. `pattern` is a
case-insensitive regex.

[cols="2,3"]
|===
|Method |Returns

|`index()`
|the current cursor; pass it to `since()` to ignore everything so far

|`since(index)`
|every `SpeechSequence` after `index`

|`all()`
|every sequence this session (`since(0)`)

|`last()`
|the most recent sequence, or `None`

|`clear()`
|drops captured speech

|`speak(text)`
|asks NVDA to speak `text`

|`cancel()`
|cancels current speech

|`cancel_count()`
|how many times speech was cancelled

|`wait_for_done(timeout=10.0)`
|returns once NVDA's event queue has drained
|===
