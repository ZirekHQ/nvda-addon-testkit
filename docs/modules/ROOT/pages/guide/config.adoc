`snapshot()` and `restore()` let a test change configuration for the duration of one test and
put it back afterwards, without needing to know every key it touched:

[source,python]
----
def test_something_under_a_changed_setting(nvda):
    snapshot = nvda.config.snapshot()
    try:
        nvda.config.set(("speech", "symbolLevel"), "all")
        ...
    finally:
        nvda.config.restore(snapshot)
----
